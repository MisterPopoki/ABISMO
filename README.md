# Abismo

Demo jugable de **Abismo**, un juego 2D de buceo: desciende lo más hondo posible en una fosa oceánica,
gestionando presión, frío, gases y fauna, y mejora el submarino entre inmersiones.

**Jugar:** abre la página de GitHub Pages del repositorio. En Android (Chrome) se puede instalar como app
con el menú ⋮ → «Instalar aplicación»; en iPhone, con Compartir → «Añadir a pantalla de inicio».

La partida se guarda en el propio navegador. Para pasarla a otro dispositivo: Opciones → guardar en el dispositivo.
